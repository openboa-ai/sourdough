# Board Client build contract

The Board Client is a React 19 web presentation application built with `@openboa/yogurt` (`0.2.0-local.1`), `@ui-sdk/react` (`0.1.0-beta.13`), and `@ui-sdk/core` (`0.1.0-beta.13`), replacing the superseded `apps/board/` v0 native Zig (`0.16.0`) / Native SDK (`0.11.1`) GPU-surface target. Pin the React UI dependencies and design-system bundle solely in the Client build manifest and lockfile, never in the Python company service. The UI package supplies presentation; `CompanyDaemon` supplies the local Unix domain socket (UDS) Control Plane; neither is the operating system of the company or a prerequisite for the first Agent paper trade.

**`@openboa/yogurt` is an upstream design system.** Install and import its released web UI assets (`--target web`) into the Sourdough Board Client. It is not the client itself, a runtime service, a data provider, or part of the company and quant system model. The compiled client owns its behavior and bundles the components, CSS `@layer` styles, and tokens it uses. No company operation or read API needs a connection to the package publisher.

## Visual and accessibility baseline

Pin and preserve the `@openboa/yogurt` `0.2.0-local.1` and `@ui-sdk/react` / `@ui-sdk/core` `0.1.0-beta.13` presentation contract defined in [Design system specification](design-system/intent.md), [Tokens and layout](design-system/tokens-and-layout/spec.md), and [Yogurt component mapping](design-system/yogurt-components/spec.md):

- **CSS `@layer` Cascade & Root Scope**: Import `@openboa/yogurt/styles.css` first in the Client entrypoint so `@layer ui-sdk, yg.tokens, yg.base, yg.components, yg.patterns, yg.utilities;` governs all cascade order, and wrap the application root in `<Yogurt appearance="auto" material="neutral">`. Keep every application-level stylesheet inside an explicit `@layer` and enforce `@container` inline-size breakpoints (`{360, 480, 720, 1024}px`) rather than viewport `@media` queries inside multi-pane panels.
- **4-Element Global Header, Zero Right Drawers & 4 Domain Compositions**: Render the strictly 4-slot `48px` Global Header (`chrome/global-header`), keeping `PageHeader` (`Breadcrumb`), consolidated `Notice[urgent]`, inline `CommandOutboxPanel`, and `/` `Since Last Visit` strictly below the header. Prohibit `Y.Sheet` (`.yg-sheet`) and all right slide-over drawers or right inspector panes across 100% of screens and breakpoints; transition main views (`Tier 0 -> Tier 1`) with deterministic focus restoration on Back/`Escape`. Implement the four domain compositions (4-Element Global Header, Modern Studio Floor Map `role="grid"` with `>= 12px` density scaling, Portfolio KPI Cards & `0%`/`$0` baseline `PortfolioChart` with `null`-gap breaks, and Universal Human-Language Confirmation Sheet contrasting **What changes** vs **What stays untouched**).
- **Palette, Contrast & Signal Discipline**: Use the `21 x 11` (`231`-color) palette with quiet warm-neutral (`#FFFFFF` / `#F4F4F1`) and dark (`#0A0A0D` < `#131317` < `#1D1D22`) surfaces and monochrome `--yg-inverse` for everyday controls (`Button`, `Switch`, `Checkbox`, `RadioGroup`, `Toggle`, `ToggleGroup`, `Tabs`, `Toast`). Reserve OpenBoa Ink Blue (`#175174` with `#FFFFFF` text) exclusively for explicit human commitment CTAs (`Approve`/`Decline` decision confirmations, `Register Owner`, `Amend Charter`, `Activate Strategy Release`, `Cut Checkpoint`, `Restore Checkpoint`, `Release Quarantine`, `Resume Risk`) while using `tone="danger"` for destructive stops/revocations/quarantines/rollbacks (with zero Board employee-retirement write CTAs). Use readable `--yg-brand-ink` for links, unified `outline: none` dual-halo `:focus-visible` rings, progress fills, and chart series strokes; darken hairlines from `--yg-border-chrome` to `--yg-border-strong` on hover; enforce `var(--yg-off)` `>= 3:1` Switch off-track contrast, `AgentRow <= 44px` height caps, `Badge` `dot={false}` on non-pure-digit strings, `thead th, th[scope="col"]`-only table shading, and `0` `Button[data-tone="accent"]`.
- **Local Font Bundling & Concentric Geometry**: Bundle `Rethink Sans` variable `.woff2` font assets (`rethink-sans.woff2`, `rethink-sans-italic.woff2`) directly inside the Client build output with zero external font or CDN fetches, apply `--boa-font-mono` (`0.8125rem / 1.55`) on `CodeBlock` and `Trace` indices, and apply `tabular-nums` for all numeric amounts, quantities, revisions, timestamps, and sequence numbers. Restrict radii strictly to `{4, 6, 8, 12, 16, 20, 999}px`, use `1px` alpha hairlines, and enforce `0` CSS gradients and `0` static card box-shadows (elevation shadows belong solely to transient floating overlays such as dialogs, menus, popovers, and bottom drawers).
- **`AgentReady` & Accessibility Controls**: Keep `createYogurtAgent` disabled by default (`allow: () => false`) and allow only read-only `snapshot()`/`query()` when explicitly opted in. Assign unique accessible labels to every interactive control, isolate `keepMounted` modal labels from background triggers, expose `definePrimitive` `agent.actions` on the Floor Map `role="grid"`, propagate `details.source` (`ButtonActionDetails`, `@experimental` in `0.1.0-beta.13`) via `withSource` (`@experimental`, imported from `@ui-sdk/react/observe` or `@ui-sdk/core/observe`) across `await`, and place descriptive non-empty `data-agent-confirm` attributes solely on explicit confirmation `SDKButton` (`import { Button as SDKButton } from "@ui-sdk/react/button"`) triggers inside `ControlledConfirmDialog` (preserving `opened.current`, `changed`, `sent.current`, and `details?.source !== "agent"` rejection), `data-agent-hidden` on redacted/host-locked DOM, and `data-agent-secret` on sensitive credential or proof inputs. Verify human keyboard and screen-reader paths independently via Playwright/DOM and accessibility checks on all routes using raw-HTML interactive Yogurt controls omitted from `createYogurtAgent.snapshot()` and `query()` (`SidebarItem` `<a>`/`<button>`, `SidebarSubmenu` `<button>`, `AgentRow` `<button>`, `DataTable` sort header buttons `<button class="yg-table-sort">`, `DisclosureRow` `<details>`, `ListRow` interactive triggers `<a>`/`<button>` via `href`/`onActivate`, `ResourceRow` `<button>` via `onOpen`, `Link` `<a>`, `Chart` readings `<details>`, and `TaskList` step `<details>`).

## Host topologies and `apps/board/` disposition

Because `@openboa/yogurt` `0.2.0-local.1` targets `--target web` exclusively (`yogurt.mjs` rejects `--target native`) and `apps/board/` v0 (`app.native`, `prepare-ui.sh --target native`, `main.zig` `.gpu_surface`, per-click `sourdough client-bridge` subprocesses) lacks command submission, live event streaming, and `(company_id, principal_id)` pending isolation—and per the recorded 2026-11-25 host capability probe (`native` `0.11.1` and `zig` `0.16.0` absent on host; see [Transport, loopback bridge, and role authorization](control-plane/bridge-and-auth/spec.md))—the React 19 bundle supports two host topologies defined in [Client architecture](architecture.md):

1. **Primary standalone host (`sourdough client-web`, locked primary host)**: Serve the compiled React 19 bundle behind an authenticated local loopback HTTP-to-UDS bridge (`127.0.0.1:<ephemeral>`) communicating solely with `CompanyDaemon` over its `0o600` UDS socket (`/v1/*`).
2. **Probe-gated desktop host (`zero://app` WebView)**: `apps/board/` (`Native SDK 0.11.1`, pre-`0.2.0` Yogurt pin, zero `node_modules/`) remains superseded/probe-gated; any future reuse as a desktop WebView shell loading the compiled React 19 bundle from `zero://app` requires passing a Native SDK `0.11.1` capability probe verifying system WebView rendering, `zero://app` CSP, and bounded JS-to-Zig IPC preserving `pending.zig`'s `0o600` `O_NOFOLLOW` `board-pending` persistence and UDS isolation.

## Build and verification rules

1. At implementation, verify the upstream `@openboa/yogurt` (`0.2.0-local.1`), `@ui-sdk/react` (`0.1.0-beta.13`), and `@ui-sdk/core` (`0.1.0-beta.13`) distributions (`yogurt.config.json` with `target: "web"`), immutable revisions, supported public exports (`@stable` vs `@experimental` pinning—explicitly tracking `@ui-sdk/react/observe` / `@ui-sdk/core/observe` `withSource`, `@ui-sdk/core/button` / `@ui-sdk/react/button` `ButtonActionDetails`, `spatialMove`, `createGridFocus`, `definePrimitive({ agent })`, `@ui-sdk/react/waterfall`, and `@ui-sdk/react/timeline` as `@experimental` in `0.1.0-beta.13`), `Rethink Sans` `.woff2` asset licenses, and integrity. Pin them solely in the client `package.json` and lockfile. Do not invent a registry name, package command, or component API.
2. Only the client presentation layer imports UI assets. Keep work and financial data, access rules, authority checks, and command schemas in their owning Python/SQLite contracts. No operational Python package imports the client or its Node/UI dependencies.
3. Verify a clean production build using the pinned artifacts (`--target web`). Confirm `@layer ui-sdk, yg.tokens, yg.base, yg.components, yg.patterns, yg.utilities;` cascade ordering, `0` CSS gradients, `0` static card shadows, `{4, 6, 8, 12, 16, 20, 999}px` radii, `#175174` reservation strictly on human commitment CTAs, `var(--yg-off)` `>= 3:1` Switch off-track contrast, `AgentRow <= 44px`, `thead th`-only table shading, local `Rethink Sans` `.woff2` bundling, zero raw HTML interactive/heading/paragraph tags (`<button>`, `<input>`, `<select>`, `<textarea>`, `<a>`, `<details>`, `<h1>..<h6>`, `<p>`) bypassing Yogurt primitives, zero `Y.Sheet`/right-drawer DOM across all breakpoints, strictly 4-slot `48px` Global Header ceiling, all 4 Custom Compositions, and zero copying of upstream example templates or non-Sourdough personas. Exercise authorized queries, NDJSON `/v1/events` streaming, `createYogurtAgent` `details?.source === "agent"` rejection, `data-agent-hidden` / `data-agent-secret` redaction, `PortfolioChart` / `Chart` `0%`/`$0` baseline and `null`-gap `"Unavailable"` / `"No reading"` honesty, and explicit command/receipt cycles against the live local `CompanyDaemon` UDS service, not only a static fixture. Capture the running client's keyboard paths (including `/office` 2D `role="grid"` focus recovery and raw-HTML composites omitted from `agent.snapshot()`), contrast, `1.00×` logical-width visual captures with interactive overlays (`Dialog`/`AlertDialog`, `Popover`, `ActionMenu`, `ContextMenu`, `DisclosureRow`, `Toast`) in their open state, all 5 UI states (`empty`, `loading`, `error`, `stale`, `locked` [`controls_locked` + `host_locked`]), and all 8 `CommandLifecycle` states (`idle`, `draft`, `submitting`, `unknown`, `accepted`, `applied`, `denied` [`conflicting_revision`], `not_found_retry_choice`), plus pass the workspace external-reference privacy guard against staged additions before committing. Re-test after upgrades; use an older client only with a compatible `control-plane-v1` service contract (`GET /v1/meta`).
4. If a release or required export is unavailable, record a **client-build** gap. Do not install a substitute into the company service, invent an upstream API, or call a mock screen a verified client. Headless operating and recovery tests remain independent.
