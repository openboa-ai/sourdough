# Board Client build contract

The Board Client is a React 19 web presentation application built with `@openboa/yogurt` (`0.2.0-local.1`), `@ui-sdk/react` (`0.1.0-beta.13`), and `@ui-sdk/core` (`0.1.0-beta.13`), superseding the archived `apps/board/` v0 native Zig (`0.16.0`) / Native SDK (`0.11.1`) GPU-surface skeleton. Pin React UI dependencies and design-system bundles solely in `apps/client/package.json` and its lockfile, never in the Python company service. The UI package supplies presentation; `CompanyDaemon` supplies the local Unix domain socket (UDS) Control Plane; neither is the operating system of the company or a prerequisite for autonomous operation.

**`@openboa/yogurt` is an upstream design system.** Install and import its released web UI assets (`--target web`, declared in `apps/client/yogurt.config.json`) into the Sourdough Board Client. It is not the client itself, a runtime service, a data provider, or part of the company and trading system model. The compiled client owns its behavior and bundles the components, CSS `@layer` styles, and tokens it uses. No company operation or read API needs a connection to the package publisher.

## Visual and accessibility baseline

Pin and preserve the `@openboa/yogurt` `0.2.0-local.1` and `@ui-sdk/react` / `@ui-sdk/core` `0.1.0-beta.13` presentation contract defined in [Design system specification](design-system/intent.md), [Tokens and layout](design-system/tokens-and-layout/spec.md), and [Yogurt component mapping](design-system/yogurt-components/spec.md):

- **CSS `@layer` Cascade & Root Scope**: Import `@openboa/yogurt/styles.css` first in `apps/client/src/main.tsx` so `@layer ui-sdk, yg.tokens, yg.base, yg.components, yg.patterns, yg.utilities;` governs all cascade order, and wrap the application root in `<Yogurt appearance={appearance} material={material} className="sd-stage">` (`appearance: "light" | "dark" | "auto"`, default `"light"`; `material: "neutral" | "paper" | "mist"`, default `"neutral"`). Keep every application-level stylesheet inside an explicit `@layer` and enforce `@container` inline-size breakpoints (`{360, 480, 720, 1024}px`) rather than viewport `@media` queries inside multi-pane panels.
- **4-Slot Header, `SidebarFooter` Diagnostics, Zero Right Drawers & Core Compositions**: Render the strictly 4-slot `<header className="sd-topbar">` (`Brand`, `Approvals` pill, `⌘K` Command Palette `Dialog`, `Theme Toggle`), place connection `<Status>` diagnostics in `SidebarFooter` linking to `/audit?tab=daemon`, and keep sub-header notices and inline `CommandOutboxPanel` strictly below the header. Prohibit `Y.Sheet` (`.yg-sheet`) and all right slide-over drawers or right inspector panes across 100% of screens and breakpoints; transition main views (`Tier 0 -> Tier 1`) with deterministic focus restoration on Back/`Escape`. Implement the core domain compositions (`AppShell` Modular IA with dynamic `Trading` `DomainModule`, `AgentsActivityView` `/agents` Graph/List + `AgentDetailView`, `TradingDeskView` `/`/`/trading/live`/`/trading/paper` 4-KPI top band & `0%`/`$0` baseline `PortfolioChart` with `null`-gap breaks and `Shadow Benchmark` overlay, and `ControlledInlineConfirm` contrasting **What changes** vs **What stays untouched**).
- **Palette, Contrast & Signal Discipline**: Use the `21 x 11` (`231`-color) palette with quiet warm-neutral (`#FFFFFF` / `#F4F4F1`) and dark (`#0A0A0D` < `#131317` < `#1D1D22`) surfaces and monochrome `--yg-inverse` for everyday controls (`Button`, `Switch`, `Checkbox`, `RadioGroup`, `Toggle`, `ToggleGroup`, `Tabs`, `Toast`). Reserve OpenBoa Ink Blue (`#175174` with `#FFFFFF` text) exclusively for explicit human commitment CTAs (`Approve`/`Decline` decision confirmations, `Register Owner`, `Activate Strategy Release`, `Cut Checkpoint`, `Promote to Live`, `Resume`) while using `tone="danger"` for destructive stops/interrupts/cancellations/demotions/rollbacks (with zero Board employee-retirement write CTAs). Use readable `--yg-brand-ink` for links, unified `outline: none` dual-halo `:focus-visible` rings, progress fills, and chart series strokes; darken hairlines from `--yg-border-chrome` to `--yg-border-strong` on hover; enforce `var(--yg-off)` `>= 3:1` Switch off-track contrast, `AgentRow <= 44px` height caps, `Badge` `dot={false}` on non-pure-digit strings, `thead th, th[scope="col"]`-only table shading, and `0` `Button[data-tone="accent"]`.
- **Local Font Bundling & Concentric Geometry**: Bundle `Rethink Sans` variable `.woff2` font assets directly inside the Client build output with zero external font or CDN fetches, apply `--boa-font-mono` (`0.8125rem / 1.55`) on `CodeBlock` and `Trace` indices, and apply `tabular-nums` for all numeric amounts, quantities, revisions, timestamps, and sequence numbers. Restrict radii strictly to `{4, 6, 8, 12, 16, 20, 999}px`, use `1px` alpha hairlines, and enforce `0` CSS gradients and `0` static card box-shadows (elevation shadows belong solely to transient floating overlays such as dialogs, menus, and popovers).
- **`AgentReady` & Accessibility Controls**: Keep `createYogurtAgent` disabled by default (`allow: () => false`) and allow only read-only `snapshot()`/`query()` when explicitly opted in. Assign unique accessible labels to every interactive control, isolate `keepMounted` modal labels from background triggers, propagate `details.source` (`ButtonActionDetails`, `@experimental` in `0.1.0-beta.13`) across `await`, and place descriptive non-empty `data-agent-confirm` attributes solely on explicit confirmation `SDKButton` (`import { Button as SDKButton } from "@ui-sdk/react/button"`) triggers inside `ControlledInlineConfirm` (preserving `opened.current`, `changed`, `sent.current`, and `details?.source !== "agent"` rejection), `data-agent-hidden` on redacted/host-locked DOM, and `data-agent-secret` on sensitive credential or proof inputs. Verify human keyboard and screen-reader paths independently via Playwright/DOM and accessibility checks on all routes using raw-HTML interactive Yogurt controls omitted from `createYogurtAgent.snapshot()` and `query()`.

## Host topology and `apps/board/` disposition

`ClientWebBridge` (`sourdough client-web`, or integrated via `sourdough run-company ... --web-port <port>`) serves the compiled React 19 bundle behind an authenticated local loopback HTTP-to-UDS bridge (`127.0.0.1:<port>`) communicating solely with `CompanyDaemon` over its `0o600` UDS socket (`/v1/*`). The legacy `apps/board/` v0 directory (`app.native`, `prepare-ui.sh --target native`, `main.zig`) is archived/superseded and is not part of the active client build.

## Build and verification rules

1. Verify the upstream `@openboa/yogurt` (`0.2.0-local.1`), `@ui-sdk/react` (`0.1.0-beta.13`), and `@ui-sdk/core` (`0.1.0-beta.13`) distributions (`apps/client/yogurt.config.json` with `"target": "web"`), immutable revisions, supported public exports (`@stable` vs `@experimental` pinning), `Rethink Sans` `.woff2` asset licenses, and integrity. Pin them solely in `apps/client/package.json` and `apps/client/package-lock.json`.
2. Only the client presentation layer imports UI assets. Keep work and financial data, access rules, authority checks, and command schemas in their owning Python/SQLite contracts. No operational Python package imports the client or its Node/UI dependencies.
3. Verify a clean production build using `npm --prefix apps/client run typecheck`, `npm --prefix apps/client run check:yogurt`, and `npm --prefix apps/client run build`. Confirm `@layer ui-sdk, yg.tokens, yg.base, yg.components, yg.patterns, yg.utilities;` cascade ordering, `0` CSS gradients, `0` static card shadows, `{4, 6, 8, 12, 16, 20, 999}px` radii, `#175174` reservation strictly on human commitment CTAs, `var(--yg-off)` `>= 3:1` Switch off-track contrast, `AgentRow <= 44px`, `thead th`-only table shading, local `Rethink Sans` `.woff2` bundling, zero raw HTML interactive/heading/paragraph tags bypassing Yogurt primitives, zero `Y.Sheet`/right-drawer DOM across all breakpoints, strictly 4-slot header ceiling, and zero copying of upstream example templates or non-Sourdough personas. Exercise authorized queries, NDJSON `/v1/events` streaming, `details?.source === "agent"` rejection, `data-agent-hidden` / `data-agent-secret` redaction, `PortfolioChart` `0%`/`$0` baseline and `null`-gap `"Unavailable"` / `"No reading"` honesty, and explicit command/receipt cycles against the live local `CompanyDaemon` + `ClientWebBridge`, passing the workspace external-reference privacy guard before committing.
4. If a release or required export is unavailable, record a **client-build** gap. Do not install a substitute into the company service, invent an upstream API, or call a mock screen a verified client. Headless operating and recovery tests remain independent.
