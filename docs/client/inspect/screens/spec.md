Define the complete executive screen inventory, route taxonomy, strict 4-element global header, zero-drawer navigation model, 3-tier progressive disclosure placement, role gates, redaction rules, required 5 UI states, and `v1` (`6694fa9`) provenance tags across the **5-area Executive Information Architecture + quiet lateral `SYSTEM` section**. ### 3. Required UI states on every screen

Every route above MUST implement all five standard states consistently without layout collapse or hidden failure:

1. **`empty`**: Domain-accurate empty state explaining why no records exist yet (e.g., `"Paper profile not enabled on this company"`, `"No active paper orders"`, `"No open reserved decisions"`, Day 0 studio bays with `"Ask CEO about first hire"`). Never renders numeric `$0.00` balances as stand-ins for absent profiles or missing closes.
2. **`loading`**: Initial `connecting` / fetch skeleton preserving the 4-element Global Header; never replaces already-verified `Data State` during routine background refreshes.
3. **`error`**: Explicit failure `Notice` on `incompatible` contract version, malformed payload, or `401`/`403` access denial (paired with immediate `clearData()` on `401`/`403`/scope mismatch), showing HTTP status / `denial_code` and a retry or scope-selection action.
4. **`stale`**: Triggered on transient UDS disconnect (`link_state = "disconnected"`, `stale = true`, `controls_locked = true`). Retains last verified `Data State` intact beneath a consolidated sub-header `Notice` displaying `as_of_ns` and disconnect duration while disabling all mutating controls.
5. **`locked`**: Two strictly disjoint sub-modes: (a) **`controls_locked`** (`bootstrap_locked`, `board_viewer`, `stale`, or in-flight `pending` / `unknown` command) keeps read projections visible while disabling command triggers with an explicit reason chip (`bootstrap_locked` isolates UI on `/bootstrap` with `register_owner` only); (b) **`host_locked`** mounts the full-viewport opaque Privacy Shield (`data-agent-hidden`) over protected DOM without mutating `as_of_ns` or `stale`.
