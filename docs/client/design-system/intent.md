# Align Client presentation with the Yogurt design system

Design draft · [Board Client](../README.md) · [Client architecture](../architecture.md) · [Client build contract](../build.md) · [System map](../../README.md) · [Development lifecycle](../../engineering/lifecycle.md)

Business situation: [Set direction and inspect it](../../capabilities.md#mandate).

## Operating need

A Board principal overseeing an autonomous paper-trading company—monitoring live paper portfolio health and trade execution on the primary view, inspecting the living office floor, conversing 1:1 with the CEO, reviewing reserved approvals, or accessing quiet continuity and offline evaluation views—needs a calm, visually disciplined, keyboard-accessible presentation layer built on `@openboa/yogurt` (`0.2.0-local.1`), `@ui-sdk/react` (`0.1.0-beta.13`), and `@ui-sdk/core` (`0.1.0-beta.13`). Across all five global chrome surfaces and the `20` route table rows covering `24` URL patterns of Sourdough's **5-area Executive Information Architecture + `/bootstrap`, `/restrictions`, and quiet lateral `SYSTEM` section** (where `/system/evaluations` covers `/suites`, `/grading`, and `/lineage`), every control surface, strictly 4-element `48px` Global Header, zero-drawer full-screen transition, human-language confirmation sheet, chart, and spatial grid must derive directly from Sourdough's operational domain and Board-vs-CEO authority boundaries without copying upstream design-system example templates, while isolating presentation dependencies from Python/SQLite domain owners.

## Observable outcome

The Board Client maps every global chrome surface, route, and custom domain composition unambiguously to pinned `@openboa/yogurt` (`0.2.0-local.1`) tokens, CSS `@layer` stylesheets, verified primitives, or documented `@ui-sdk/react` / `@ui-sdk/core` (`0.1.0-beta.13`) compositions:
1. **Desktop shell, palette, and zero-drawer discipline:** Visual hierarchy uses quiet warm-neutral (`#FFFFFF` / `#F4F4F1`) and dark (`#0A0A0D` < `#131317` < `#1D1D22`) surfaces, monochrome `--yg-inverse` everyday controls, strict `#175174` commitment-CTA reservation, `Rethink Sans` typography with `tabular-nums`, concentric `{4, 6, 8, 12, 16, 20, 999}px` radii, and zero CSS gradients or static card shadows. Navigation relies on a strictly 4-element `48px` Global Header (`chrome/global-header`) with sub-header page/banner regions (`chrome/sub-header`) and **zero right slide-over drawers (`Y.Sheet` and right inspector panes prohibited across 100% of screens and breakpoints)**.
2. **Board-vs-CEO governance & Universal Human-Language Confirmation Sheet:** Board 1:1 chat is strictly scoped to the designated Founder/CEO (`/ceo`, zero inline command execution buttons), while routine HR/offboarding remains CEO-delegated (read-only Custody & Handover Audit Ledger on `/company/org` with zero Board retirement write controls). Every mutating Board command executes inside the Universal Human-Language Confirmation Sheet (`ControlledConfirmDialog` on `@ui-sdk/react/alert-dialog` + `@ui-sdk/react/button` `Button` aliased as `SDKButton`) contrasting plain-language **What changes** against **What stays untouched** (`RecordFacts` `<dl>`), collapsing technical revisions/hashes/CAS IDs inside `DisclosureRow` `"Technical details"`, preserving revision latching, stale-decision warnings, one-shot guards, and explicit `details?.source !== "agent"` rejection alongside `createYogurtAgent` (`allow: () => false`) `AgentReady` redaction (`data-agent-confirm`, `data-agent-secret`, `data-agent-hidden`).
3. **Honest telemetry & living spatial observability:** Missing telemetry and high-baseline financial series render `"Unavailable"` / `"No reading"` and honest `0%`/`$0` baseline SVG path breaks (`PortfolioChart`) without `0`-coercion or flattened curves, while the Modern Studio Floor Map (`/office`) scales cleanly across `1–4`, `5–9`, and `10+` Agents per fixed presentation zone at `>= 12px` typography with opaque `.desk/drafts/*` handling and 2D `role="grid"` keyboard navigation.

## Scope of discretion

- **Tokens, CSS cascade, and layout grammar:** Define exact `@openboa/yogurt` token tiers, `21 x 11` palette rules, `#175174` vs `--yg-inverse` signal discipline, typography/space/radius/control grids, `@layer` cascade, `@container` responsiveness, unified dual-halo focus rings, `--yg-off` Switch track contrast, `AgentRow` `<= 44px` caps, 5-state surface rules, zero-drawer spatial grammar, and non-imitation / zero-template-copying domain derivation.
- **Component bindings, 4 domain compositions, and `AgentReady` safety:** Map all five global chrome surfaces (`chrome/global-header`, `chrome/sub-header`, `chrome/command-outbox`, `chrome/confirm-dialog`, `chrome/privacy-shield`) and all 20 route entries (24 URL patterns) across the 5-area Executive IA + quiet `SYSTEM` section to verified `@openboa/yogurt` and `@ui-sdk/react` / `@ui-sdk/core` primitives; define the **four Sourdough custom domain compositions** (4-Element `48px` Global Header, Modern Studio Floor Map, Portfolio KPI Cards & `PortfolioChart`, Universal Human-Language Confirmation Sheet); specify `ControlledConfirmDialog` and `createYogurtAgent` / WebMCP guardrails; and specify `PortfolioChart` / `Chart` high-baseline and `null`-gap behavior.
- **Strict presentation isolation:** Keep all UI packages, stylesheets, font assets, and agent-DOM attributes strictly inside the Client presentation boundary; no company, quant, or control-plane service depends on UI code or assets.
