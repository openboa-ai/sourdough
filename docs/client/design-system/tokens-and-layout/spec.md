## Design decision and review

### 1. Package pins, CSS `@layer` cascade, and root wrapper

- **Pinned package contract (`package.json` / lockfile only):**
  - `@openboa/yogurt`: `0.2.0-local.1` (`--target web` distribution only; `react` peer dependency `>=19.2.0 <20`)
  - `@ui-sdk/react`: `0.1.0-beta.13`
  - `@ui-sdk/core`: `0.1.0-beta.13`
- **CSS `@layer` import order:** Import `@openboa/yogurt/styles.css` (`design/styles/ui.css`) as the first stylesheet entry in the Client application. It establishes the explicit cascade:
  ```css
  @layer ui-sdk, yg.tokens, yg.base, yg.components, yg.patterns, yg.utilities;
  ```
  Every application-level layout stylesheet added by the Board Client MUST declare an explicit `@layer` (for example `@layer yg.patterns` or `@layer yg.utilities`) and never emit unlayered rules that override Yogurt component or focus-ring selectors.
- **Root wrapper (`@openboa/yogurt/yogurt`):** Wrap the Client shell in `<Yogurt appearance="auto" material="neutral">` (supporting operator selection of `appearance="auto" | "light" | "dark"` and `material="neutral" | "paper" | "mist"`), keeping `<div className="yg-root" data-appearance data-material>` as the CSS custom-property scope (`light-dark(...)` resolution and base typography).

### 2. Typography and quantitative scale grids

- **Typography (`design/tokens/brand.json`, `design/styles/ui.css`):**
  - **Primary typeface:** `Rethink Sans` bundled locally as variable `.woff2` font assets (`rethink-sans.woff2` normal and `rethink-sans-italic.woff2` italic, weights `400..800`, `font-feature-settings: "cv02", "cv03", "cv04", "ss01"`). Never fetch fonts from external CDNs.
  - **Role weights:** `heading: 520`, `body: 420`, `ui: 500`, `value: 540`, `wordmark: 700`.
  - **Type ramp & tracking:** Sizes `{cap: 10, caption: 11, help: 12, ui: 13, body: 14, card-title: 14, subheading: 16, section: 18, title: 24, value: 28, headline: 32}px` with paired tracking (`body -0.006`, `label -0.012`, `heading -0.022`, `display -0.03`, `meta 0.04`, `cap 0.06`, `value -0.024`).
  - **Studio Floor Map minimum readable text floor:** Across all three semantic density tiers on `/office` (`1–4` Expanded Meso Cards, `5–9` Compact 2-line Cards, and `10+` Zone Health Bar + pinned exception cards + `+N nominal` chips), readable workstation labels, states, duty summaries, and counts MUST remain `>= 12px` (`help` tier or above).
  - **Monospace & tabular numerals:** Use `--boa-font-mono` (`ui-monospace, "SF Mono", "JetBrains Mono", Menlo, monospace`) at `0.8125rem` (`13px`) / `1.55` line-height on `CodeBlock` payloads and `Trace` indices, as well as digests (`sha256`, `payload_sha256`, `bundle_sha256`) and IDs (`company_id`, `command_id`, `run_id`, `order_id`). Apply `font-variant-numeric: tabular-nums` on every monetary amount, return percentage, quantity, fill price, basis-point spread, revision, `as_of_ns`, `event_seq`, and `pending_age` counter.
- **Strict space scale (`--boa-space-*`):** `[2, 4, 6, 8, 10, 12, 16, 20, 24, 32, 40, 48, 64]px`. Off-grid spacing values (such as `14px` or `18px`) are prohibited.
- **Strict even concentric radius grid (`--yg-radius-*`):** Strictly `{4, 6, 8, 12, 16, 20, 999}px`:
  - `inset: 4px` (nested inner badges/wells)
  - `small / chip: 6px`
  - `control: 8px` (compact inputs/select controls)
  - `menu / panel: 12px` (menus, `AgentRow`, and nested subpanels)
  - `surface / card / popover / dialog: 16px` (`Card`, `Dialog` / `AlertDialog`, `Popover`, `Notice`, `Receipt`; note that while `--yg-radius-sheet: 16px` exists in upstream Yogurt CSS tokens, `Y.Sheet` desktop right slide-over drawers are **prohibited** in the Sourdough Client)
  - `feature: 20px` (elevated `Composer` / drop regions)
  - `round / pill: 999px` (pill buttons, badges, search fields, toasts, segmented pills)
  Off-scale radii (`4.5, 5, 5.5, 7, 9, 10, 11, 14, 22, 26px`) are prohibited.
- **Control height tiers (`--yg-size-*`):** `[28, 32, 36, 44]px` (`compact: 28px`, `regular: 32px`, `row / comfort: 36px`, `touch / spacious / featured: 44px`). Global Header height is locked to `48px` (`--boa-space-48`).
- **Container breakpoints:** `{ compact: 360, narrow: 480, medium: 720, wide: 1024 }px` driving `@container` layout rules.

### 3. `21 x 11` Palette, CTA signal discipline, and surface polarity

- **Unified `21 x 11` (`231`-color) palette:**
  - `3` neutral families (`neutral`, `paper`, `mist`) + `18` chromatic families (`slate`, `blue`, `indigo`, `violet`, `purple`, `magenta`, `rose`, `red`, `terracotta`, `orange`, `ochre`, `yellow`, `lime`, `green`, `sage`, `teal`, `cyan`, `earth`), each stepped monotonically across `50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950`.
  - Retired legacy tokens (`gray-green`, `coral`, `--boa-field`, `--boa-ink`, `#f2f2ed`, `--radix-popper`) must never be referenced.
- **Strict `#175174` commitment-CTA reservation vs monochrome `--yg-inverse`:**
  - **Primary OpenBoa Ink Blue (`--yg-brand` / `--yg-action` = `slate.700` `#175174`, `--yg-on-brand` = `neutral.50` `#FFFFFF`, `8.52:1` contrast in both Light and Dark):** Reserved exclusively for primary human commitment CTAs (`Confirm` / `Approve` / `Decline` confirmations in `ControlledConfirmDialog` for non-destructive governance actions, `Register Owner`, `Amend Charter`, `Bind Board Principal`, `Assign Role`, `Activate Strategy Release`, `Change Paper Binding`, `Configure Paper Runtime`, `Start Paper Runtime`, `Cut Checkpoint`, `Restore Checkpoint`, `Release Quarantine`, `Resume Risk`, `Resume Company`, `Activate Review Tool`). Destructive governance CTAs (`Suspend New Risk`, `Pause Company`, `Revoke Grant`, `Replace Role`, `Revoke Role`, `Interrupt Run`, `Cancel Work`, `Quarantine Review Tool`, `Revert Review Tool`, `Rollback Strategy`) use `tone="danger"`. Routine employee retirement is CEO-delegated inside `CompanyRuntime`—there is zero Board retirement CTA or write dialog anywhere in the Client.
  - **Readable brand ink (`--yg-brand-ink` / `--yg-action-ink` / `--yg-focus-ring`):** Adaptive `#175174` (`slate.700`) in Light and `#79B3D6` (`slate.300`) in Dark for text links, progress fills, `Chart` / `PortfolioChart` primary strokes, `6px` unread indicators, and `:focus-visible` rings.
  - **Unified dual-halo `:focus-visible` ring & border hover darkening:** Focus states MUST set `outline: none` paired with the single unified dual-halo ring (`box-shadow: 0 0 0 1.5px var(--yg-focus-ring), 0 0 0 3.5px var(--yg-focus-halo);`)—never colliding native `outline` with `box-shadow`—preserving `@media (forced-colors: active)` `CanvasText` solid outline fallback. Interactive hairlines transition cleanly from resting `--yg-border-chrome` to `--yg-border-strong` on hover.
  - **Monochrome everyday controls (`--yg-inverse` = `#0A0A0D` Light / `#F4F4F1` Dark, `--yg-on-inverse` = `#FFFFFF` Light / `#0A0A0D` Dark):** Applied to everyday controls (`Button` neutral emphasis, `Switch`, `Checkbox`, `RadioGroup`, `Toggle`, `ToggleGroup`, `Tabs` active pill, `Composer` Send, standalone `Toast`).
  - **Opt-in secondary editorial accent (`--yg-accent` = `terracotta.600` `#A64F3C` Light / `terracotta.300` `#D88F7D` Dark):** Strictly `<= 1` region per viewport for non-operational editorial callouts; **never** render `Button[data-tone="accent"]`, focus rings, or operational statuses using `--yg-accent`.
- **Surface luminance polarity & separation:**
  - **Light (`neutral`):** `backdrop (#E5E5E0) < surface / surface-list / surface-inspector / field (#F4F4F1) < canvas == raised == input-surface (#FFFFFF)`; `hover (#E5E5E0) < field (#F4F4F1)`. Inputs, active sidebar pills, `Notice`, `CodeBlock`, `RecordFacts`, and `Table` rows must maintain clear edge/fill separation against `#F4F4F1` stages.
  - **Dark (`neutral`):** `backdrop / surface / input-surface / surface-list / surface-inspector (#0A0A0D) < canvas / raised (#131317) < popover / elevated / field (#1D1D22) < hover (#2A2A30)`. Inputs sit recessed (`#0A0A0D`) inside `#131317` cards.
- **Surface, elevation, and DOM discipline:**
  - **Zero CSS gradients:** `linear-gradient`, `radial-gradient`, and `conic-gradient` are forbidden across all stylesheets.
  - **Zero static shadows & banned `Y.Sheet` overlays:** Static `.yg-card`, `.yg-surface`, `.yg-receipt`, `.yg-trace`, `.yg-facts`, `.yg-composer`, `.yg-agent-row`, and `.yg-table-scroll` surfaces enforce `box-shadow: none` with `1px solid var(--yg-border-subtle)` hairlines. Elevation shadows (`--yg-float-shadow`, `--yg-panel-shadow`) apply strictly to transient overlays (`Toast`, `Popover`, `ActionMenu`, `ContextMenu`, `Select`, `Dialog` / `AlertDialog`, and bottom drawers—root `@openboa/yogurt` `Drawer` [inherently bottom-only `.yg-drawer` taking `DialogProps` with no `side` prop] or `@ui-sdk/react/drawer` `Drawer` constrained strictly to `side="bottom"`, never `"right"`/`"end"`—if ever used on narrow viewports). **`Y.Sheet` (desktop right slide-over drawer) and right inspector panes are strictly banned across 100% of screens and breakpoints.**
  - **Opaque disabled filled buttons & `Switch` off-track contrast:** Disabled or `aria-disabled` filled buttons use opaque neutral step-down (`neutral.200` Light / `neutral.800` Dark + `--yg-text-disabled`, `opacity: 1`), never muddy `opacity: 0.42` alpha haze. Always reference semantic `var(--yg-off)` on `Switch` off tracks (never hardcoding hex values) and verify `>= 3:1` contrast between `var(--yg-off)`, the adjacent surface (`--yg-canvas` / `--yg-raised`), and `--yg-thumb` so `Default off`, `Disabled on`, and `Disabled off` stay clearly separated *(noting that `@openboa/yogurt` `0.2.0-local.1` `ui-tokens.css` / `ui.json` maps `--yg-off` to `neutral.500`, so Client contrast checks must verify `Switch` state distinguishability cleanly in both Light and Dark)*.
  - **Table header scoping:** Shade only `thead th, th[scope="col"]` (`background: var(--yg-surface)`); keep `tbody th` `background: transparent`.
  - **No raw HTML UI tags in consumer views:** Consumer React routes and domain compositions MUST NOT emit raw `<button>`, `<input>`, `<select>`, `<textarea>`, `<a>`, `<details>`, `<h1>`–`<h6>`, or `<p>` elements bypassing `@openboa/yogurt` (`Heading`, `Text`, `Link`, `Button`, `TextField`, `Select`, `Textarea`, `DisclosureRow`) or `@ui-sdk/react` primitives.
  - **Accessibility contrast floor:** Text roles maintain `>= 4.5:1` contrast and interactive control borders, focus rings, and state fills maintain `>= 3.0:1` across `neutral`, `paper`, and `mist` materials.

### 4. Spatial placement grammar and 5-state surface rules

- **Inline metadata proximity (`inlineMeta`), `AgentRow` cap, and `Badge` dot rules:** Place short status signals inline next to row titles (`ListRow.inlineMeta`, `WorkEvent.inlineMeta`), capped at **`<= 1` `Badge` plus optional `6px` unread dot** per row (`Badge` precedes unread dot). Pure numeric counts omit decorative dots: `Badge`'s automatic `isNumeric` dot suppression matches bare numbers/digits only (`/^\d+$/`), so count+noun strings such as `"3 causes"` or `"12 runs"` MUST pass `dot={false}` explicitly (or use `Count`). Constrain `AgentRow` entries to **`<= 44px` height** with `AgentAvatar` presence dot and `·` separator.
- **Trailing action isolation (`.yg-row-split`):** Whenever a `ListRow` is interactive (`href` or `onActivate`) and carries trailing `value` or `actions`, split the primary row trigger from the sibling `.yg-row-end` container so interactive controls are never nested.
- **Baseline/height parity & intrinsic button widths:** Controls aligned on one horizontal toolbar or form line (`FilterBar`, `ButtonGroup`, `Inline`) must match height tier (`[28, 32, 36, 44]px`). Action buttons (`Button`, `SDKButton`) keep intrinsic content width inside toolbars, cards, and dialogs—never stretching submit buttons full-width (`width: 100%`) across wide dialogs or toolbars.
- **Container-query responsiveness (`@container`):** In-page multi-pane main views (`@ui-sdk/react/resizable` strictly inside `/system/tools` and `/system/evaluations/lineage`, never right inspector drawers), decision trace cards, and ledger splits adapt via `@container` inline-size queries (`{360, 480, 720, 1024}px`) rather than viewport `@media` queries so panels inside `SidebarLayout` or `Resizable` splitters reflow cleanly regardless of sidebar collapse state.

#### Five-state visual matrix across all routes

| State | Visual & Token Contract | Interactive / Command State | Honesty & Privacy Rule |
| --- | --- | --- | --- |
| **`empty`** | `EmptyResult` (search query active -> `"No matches"` + `"Clear search"`) or `Result` inside `Card` explaining domain emptiness (e.g., `"Paper profile not enabled on this company"`, Day 0 dashed bays on `/office`). | Navigational links remain enabled; inapplicable commands hidden/disabled. | Never substitute numeric `0` or `$0.00` for an absent profile, missing close, or empty collection. |
| **`loading`** | `Skeleton` (`role="status"`, `lines`) inside route body while keeping the **4-element `48px` Global Header (`chrome/global-header`)** mounted. | Only initial cold load shows skeletons; routine refreshes keep verified `Data State` visible. | Never flashes or blank-wipes previously verified projections during background refresh. |
| **`error`** | Consolidated sub-header `Notice` (`tone="danger"`, `urgent={true}`, `role="alert"`) displaying HTTP status / `denial_code` and `Retry` action. | On `401`/`403`/scope mismatch: immediate `clearData()`, `controls_locked = true`. | Zero stale cached financial/decision DOM survives `401`/`403` or scope change. |
| **`stale`** | Consolidated sub-header `Notice` (`tone="warning"`, `urgent={true}`, `role="alert"`) pinned below `chrome/global-header` above preserved `Data State`, showing server `as_of_ns` and disconnect elapsed time. | `link_state = "disconnected"`, `controls_locked = true`; all mutating buttons disabled (opaque neutral step-down). | Never blank-wipes verified `Data State` on transient UDS disconnect or daemon restart. |

### 5. Non-imitation and Sourdough domain derivation

Every layout, header slot, sidebar group, route hierarchy, and domain composition derives strictly from Sourdough's **5-area Executive Information Architecture + quiet lateral `SYSTEM` section** (`20` route table rows covering `24` URL patterns across the 5-area Executive IA + `/bootstrap`, `/restrictions`, and quiet `SYSTEM`, where `/system/evaluations` covers `/suites`, `/grading`, and `/lineage`), `environment == "paper"` / `private_desk` / `offline-trial-registry-v1` contracts, and Board-vs-CEO governance boundaries—without copying external or upstream example templates, multi-bot chat rosters, channel sidebars, support consoles, marketplace directories, or slide-over computer drawers:

- **Primary entry is Live Trading & Portfolio (`/`):** When `active_domains.includes("paper")` is present in `GET /v1/meta`, the root route `/` opens directly to `/` (**Live Trading & Portfolio**: 3-second 4-KPI top band with persistent `Paper` marker, single canonical collapsible **Since Last Visit** brief, `0%`/`$0` baseline `PortfolioChart` with `null`-gap breaks, Two-Layer P&L reconciliation bridge, `100–250ms` coalesced grouped causal execution tape with `cancel != flat`, and open positions). When `"paper"` is absent, `/` degrades gracefully to an honest core-only company summary (`"Paper profile not enabled on this company"`, zero `$0.00` placeholders) linking directly to `/office`, `/ceo`, and `/company/approvals`. Sealed window NAV (`V1_SQLITE_NEEDS_UDS`) stays clearly labeled and decoupled from absent live intraday market ticks (`BACKEND_GAP #5` -> `"No live market tick"` / `"Unavailable"`).
- **Strictly 4-element `48px` Global Header + sub-header regions:** `chrome/global-header` carries solely: (1) Company Identity (`ProjectMark` + Company Name), (2) Primary View Switcher (`Live Trading`, `Office Floor`, `CEO Direct Line`, `Company`), (3) Connection & Freshness Status Trigger (`Button` wrapping `Status` opening an on-demand `Popover` for Tier 2 technical telemetry, Lock Screen trigger, and `"System Diagnostics"` link to `/system/daemon`), and (4) Primary Safety / CEO Trigger (`active_domains.includes("paper")` gated). Breadcrumbs (`Breadcrumb`), urgent `Notice` banners, inline `CommandOutboxPanel`, and `/` **Since Last Visit** live strictly below the header (`chrome/sub-header`), while technical operations (`/system/*`) live in the quiet bottom `SYSTEM` sidebar footer and Slot 3 popover.
- **Zero right slide-over drawers (`Y.Sheet` banned):** `Y.Sheet` and persistent right-hand inspector panes are prohibited across 100% of screens and responsive breakpoints. Selecting any order, workstation, run, publication, or decision transitions the main workspace view in-place (`Tier 0 -> Tier 1`, depth `<= 2`) with `Breadcrumb` (`<nav aria-label="Breadcrumb">`) inside `PageHeader` and deterministic keyboard focus restoration back to the originating row or `role="gridcell"` on Back/`Escape`.
- **Secondary living office is the Modern Studio Floor Map (`/office`):** Organized into **four fixed, flat presentation-only zones** (`CEO Office`, `Research & Strategy`, `Trading & Execution`, `Risk & Operations`) on `#FFFFFF`/`#F4F4F1` hairline surfaces (`0` gradients, `0` static card shadows, `>= 12px` text across `1–4` / `5–9` / `10+` density tiers, Day 0 dashed bays with `"Ask CEO about first hire"` / `"View Mandate"`, calm ledger-first collaboration pills + hover/focus cross-highlighting safe under `prefers-reduced-motion: reduce`, and single-Tab-stop 2D `role="grid"` keyboard navigation). Active `.desk/drafts/*` remain strictly opaque (`"Private Desk · N drafts (not shared)"` only; zero draft-peeking panels).
- **Board-vs-CEO boundary & Universal Confirmation Sheet:** `/ceo` is strictly a 1:1 Board ↔ Founder/CEO advisory thread (`send_ceo_message`) with pinned read-only `Contextual Ask CEO` cards (`zero` inline command buttons, `zero` non-CEO 1:1 chat routes, and `zero` Board chat composers on `/office/agents/:agentId`). Routine employee retirement is CEO-delegated inside `CompanyRuntime`; `/company/org` renders a read-only Custody & Handover Audit Ledger (`"Managed by CEO · Board view is read-only"`, zero Board retirement buttons). Every mutating governance command routes through the centered Universal Human-Language Confirmation Sheet (`ControlledConfirmDialog` on `@ui-sdk/react/alert-dialog` + `@ui-sdk/react/button` `SDKButton`) contrasting **What changes** vs **What stays untouched** (`RecordFacts` `<dl>`) with technical revisions/hashes/CAS IDs collapsed inside `DisclosureRow` `"Technical details"`, handing off on click to the inline `CommandOutboxPanel` (`Receipt`).

## Operations and change review

Any upgrade to `@openboa/yogurt` or `@ui-sdk/react` requires re-verifying CSS `@layer` precedence, palette step contrast (including `var(--yg-off)` `Switch` track states), concentric radius compliance, zero-drawer enforcement, and clean-build font bundling inside the Client workspace before updating the pinned lockfile.
