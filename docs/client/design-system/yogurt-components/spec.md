## Boundary and dependencies

Bind every global shell, route, domain composition, confirmation gate, browser-agent policy, and telemetry chart in the Board Client strictly to verified `@openboa/yogurt` (`0.2.0-local.1`) and `@ui-sdk/react` (`0.1.0-beta.13`) / `@ui-sdk/core` (`0.1.0-beta.13`) APIs. All components consume service read models (`GET /v1/meta`, `GET /v1/projections/*`, `GET /v1/events`) and submit commands solely via `POST /v1/commands` and `GET /v1/commands/{command_id}?operation=...`. No domain or control-plane service depends on UI component bindings.

Input contracts: [Tokens and layout](../tokens-and-layout/spec.md) · [Client screens and navigation](../../inspect/screens/spec.md) · [Flow observability](../../inspect/flow-observability/spec.md) · [Command submission](../../commands/submit/spec.md) · [Meta and authorized read projections](../../control-plane/projections/spec.md). These are public client and service contracts, not imports of service implementations.

## Design decision and review

### 1. Verified primitive catalog and missing-export prohibitions

Use **only** verified public exports from `@openboa/yogurt` (`0.2.0-local.1`) and `@ui-sdk/react` (`0.1.0-beta.13`):

- **Verified `@openboa/yogurt` (`0.2.0-local.1`) exports:**
  - *Foundation & layout:* `Yogurt`, `Heading`, `Text`, `Icon`, `Stack`, `Inline`, `Grid`, `Surface`, `Card`, `Divider`, `ScrollArea`
  - *Actions & forms:* `Button`, `IconButton`, `ButtonGroup`, `TextField`, `SearchField`, `Textarea`, `Select`, `Combobox`, `Checkbox`, `RadioGroup`, `Switch`, `Slider`, `RangeSlider`, `Calendar`, `InputOTP`
  - *Navigation & collections:* `Link`, `Breadcrumb`, `NavigationList`, `Tabs`, `SegmentedControl`, `Pagination`, `FilterBar`, `Count`, `List`, `ListRow`, `EmptyResult`, `SidebarLayout` (`SidebarTrigger`, `SidebarHeader`, `SidebarContent`, `SidebarFooter`, `SidebarGroup`, `SidebarSubmenu`, `SidebarItem`)
  - *Feedback, data & decisions:* `Badge`, `Status`, `Notice`, `Skeleton`, `Progress`, `Toast`, `Result`, `RecordFacts`, `Table`, `DataTable`, `Chart`, `Receipt`
  - *Layers, identity & operations:* `DisclosureRow` (`Disclosure`), `ActionMenu`, `Popover`, `Dialog`, `Sheet`, `Drawer` (root `@openboa/yogurt` export only; no `./drawer` subpath), `Tooltip`, `CodeBlock`, `ResourceRow`, `WorkEvent`, `AgentAvatar`, `AgentRow`, `Transcript`, `Composer`, `TaskList` (`@openboa/yogurt/motion-task-list`), `createYogurtAgent` (`@openboa/yogurt/agent`)
- **Verified `@ui-sdk/react` (`0.1.0-beta.13`) subpath entries for custom domain compositions:**
  - `@ui-sdk/react/button` (`Button` as `SDKButton`), `@ui-sdk/react/alert-dialog`, `@ui-sdk/react/meter`, `@ui-sdk/react/timeline`, `@ui-sdk/react/waterfall`, `@ui-sdk/react/tree`, `@ui-sdk/react/resizable`, `@ui-sdk/react/number-input`, `@ui-sdk/react/date-input`, `@ui-sdk/react/time-input`, `@ui-sdk/react/date-picker`, `@ui-sdk/react/agent` (`createAgent`, `registerTools`).
- **Missing-export prohibitions:** Never cite absent symbol names as `@openboa/yogurt` exports:
  - Do not cite `Banner` or `Alert` (use `Notice` with `urgent={true}` for `role="alert"`).
  - Do not cite `Input` (use `TextField` or `@ui-sdk/react/input` styled with `.yg-input`).
  - Do not cite plural `Breadcrumbs` (use singular `Breadcrumb`).
  - Do not cite `Radio` (use `RadioGroup`), `NumericSpinner` (use `@ui-sdk/react/number-input`), `DatePicker` (use `@ui-sdk/react/date-picker`), or `Stat` / `Metric` / `KeyValue` (use `RecordFacts` for key-value telemetry).
  - **Missing-reading ban on `StatCard`:** `@openboa/yogurt/motion-stat-card` exports `StatCard` (whose unexported internal helper `StatSeries` coerces non-finite values to `0` via `Number.isFinite(value) ? value : 0`; `StatSeries` is not a public export). Never use `StatCard` for financial, P&L, or sparse operational telemetry; use `RecordFacts`, `Chart`, and `DataTable`.

### 4. `ControlledConfirmDialog` and `createYogurtAgent` / WebMCP safety spec

#### 4.1 Why `ControlledConfirmDialog` builds the confirm button on `@ui-sdk/react/button` (`SDKButton`)

Inspected directly in `@openboa/yogurt` `0.2.0-local.1`:
- Yogurt `Button` (`packages/web/src/controls/actions.tsx:8-52`) types `onClick` as single-argument `MouseEventHandler<HTMLButtonElement>` and invokes `onClick?.(event)`, **dropping `@ui-sdk/react/button`'s second argument `details: ButtonActionDetails`** (`{ source: "mouse" | "touch" | "pen" | "keyboard" | "virtual" | "programmatic" | "agent" }`).
- Yogurt `ConfirmDialog` (`packages/web/src/patterns/decisions.tsx:21-88`) wraps Yogurt `Button`, does **not** accept or forward `data-agent-confirm`, and passes zero `details` to `onConfirm`.

Therefore, Sourdough MUST NOT use unwrapped `ConfirmDialog` or Yogurt `Button` for mutating command confirmation. `ControlledConfirmDialog` composes `Dialog` (`@openboa/yogurt/dialog`) + `Stack` + `ButtonGroup` (`label="Decision"`, `justify="end"`) + quiet `Cancel` (`Button` `emphasis="quiet"`) + confirm trigger built directly on `@ui-sdk/react/button` (`SDKButton`) styled with Yogurt's `.yg-button` classes (`data-emphasis="filled"`, `data-tone={decision.destructive ? "danger" : "brand"}`, `data-control-size="regular"`, `data-shape="pill"`).

#### 4.2 Five mandatory invariants of `ControlledConfirmDialog`

1. **Revision latch (`opened.current`):** On `open === true`, latch `opened.current = { id: decision.id, revision: decision.revision }` once (covering composite preconditions such as `${company_id}:${charter_revision}:${expected_revision}`, `${question_id}:${revision}:${payload_hash}`, or `${restriction_id}:${expected_restriction_revision}:${charter_revision}`). Reset `opened.current = null` and `sent.current = false` when `!open`.
2. **Mid-review mutation detection (`changed`) & warning banner:** Compute `const changed = opened.current !== null && (opened.current.id !== decision.id || opened.current.revision !== decision.revision);`. When `changed` is true, render an inline `<Text className="yg-error" role="status">This decision changed. Close and review it again.</Text>` (or `Notice` `role="status"`) and disable the confirm `SDKButton` (`disabled={!decision.available || !!changed || pending}`).
3. **One-shot submit guard (`sent.current`) & immediate modal handoff:** Inside confirm `SDKButton`'s `onClick(event, details)`:
   - First check `if (details?.source === "agent") { event.preventDefault(); return; }` (rejects autonomous agent clicks on all 26 human-reserved governance/control commands).
   - Guard against double-submit or stale latch: `if (sent.current || !decision.available || !opened.current || changed) return;`.
   - Set `sent.current = true;`, close immediately via `onOpenChange(false);`, and dispatch `onConfirm({ ...opened.current })` to `CommandOutboxPanel`.
4. **Distinct specific confirm verb & `#175174` / `danger` tone:** Use `<ButtonGroup label="Decision" justify="end">` with quiet `Cancel` on the start edge and an intrinsic-width confirm button whose verb names the specific consequence (e.g., `"Suspend new paper risk"`, `"Amend charter"`, `"Quarantine review tool"`, distinct from generic `"OK"` or the opening button's label if ambiguous). Non-destructive governance commitments use `tone="brand"` (`#175174`); destructive stops/revocations/quarantines/rollbacks use `tone="danger"`.
5. **Confirm-only `data-agent-confirm` placement:** Set a descriptive non-empty sentence `data-agent-confirm={decision.consequence}` **exclusively on the confirm `SDKButton`** — never `""`, never on `Dialog` content, and never on `Cancel`.

#### 4.3 `createYogurtAgent`, WebMCP, and DOM redaction policy

- **Disabled by default (`allow: () => false`):** Any `createYogurtAgent({ allow })` bridge mounted in the Client defaults to `allow: () => false` (omitting `allow` is forbidden and throws a synchronous `TypeError: "A host action policy is required to create a Yogurt agent."`). When enabled by explicit host configuration for read-only inspection, `allow` permits **only** read-only `snapshot()` / `query()` inspection and rejects mutating `act()` steps (`allow` returns `false`): when `step.confirm` is present, `act()` fails with `"The person said no to \"<confirm text>\"."`; when no `confirm` string is present, `act()` fails with `"The app refused <action> on <ref>."` (`"Needs a person: ..."` is thrown only by raw `@ui-sdk/react/agent`'s `createAgent()` when `allow` is omitted, which `createYogurtAgent` disallows).
- **Explicit human-gate & no-rollback semantics:** `data-agent-confirm` does **not** block `act()` on its own when `allow` returns `true` (`act()` succeeds with `ok: true` and invokes handlers with `details.source === "agent"`): human safety relies on **both** `allow: () => false` (default) / rejecting `step.confirm` and mutating actions when opted in **and** `ControlledConfirmDialog`'s `details?.source === "agent"` handler rejection. `registerTools(agent, { allow })` (WebMCP `document.modelContext.registerTool`) marks `snapshot`/`query` `readOnlyHint: true`, `act` `consequentialHint: true`, and all tools `untrustedContentHint: true`. Note that `agent.act({ steps })` executes steps sequentially **without transaction rollback** if a later step fails, and `{ ok: true }` from `act()` does **not** guarantee state acceptance when an application handler calls `details.cancel()` or ignores `details.source === "agent"`.
- **Full `data-agent-hidden` and `data-agent-secret` matrix:**
  - `data-agent-hidden`: Applied to the Host-Lock Privacy Shield protected root (`host_locked`), host-denied `401`/`403` screens, `ControlledConfirmDialog` confirm regions under `board_viewer`/`controls_locked`, and ephemeral `Toast` overlays so `snapshot()`, `query()`, and `subscribe()` omit those subtrees completely.
  - `data-agent-secret`: Applied to `OwnerProof` challenge-response fields (`/overview/bootstrap`), `InputOTP` / verification inputs, and any transient auth/session handle displays so `value`, `previous`, and `errors` read `"[redacted]"` in `snapshot()`, `act()`, and `subscribe()`.
- **Raw-HTML interactive `snapshot()` / `query()` caveat:** Several `@openboa/yogurt` `0.2.0-local.1` interactive components and sub-elements render raw HTML (`<a>`/`<button>`/`<details>`) rather than `@ui-sdk/react` primitives and are therefore omitted from `createYogurtAgent.snapshot()` / `query()` trees: `SidebarItem` (`<a>`/`<button>`), `SidebarSubmenu` (`<button>`), `AgentRow` (`<button>`), `DataTable` sort header buttons (`<button class="yg-table-sort">`), `DisclosureRow` (`<details>`), `ListRow` interactive triggers (`<a>`/`<button>` via `href`/`onActivate`), `ResourceRow` (`<button>` via `onOpen`), `Link` (`<a>`), `Chart` readings `<details>`, and `TaskList` step `<details>`. Independent Playwright/keyboard/screen-reader accessibility checks are REQUIRED on all routes using these controls rather than relying on `snapshot()` alone.

### 5. `Chart` high-baseline framing and `null`-gap honesty spec

Inspected directly in `@openboa/yogurt` `0.2.0-local.1` (`packages/web/src/controls/data.tsx:183-322`):
- **Verified signature:** `Chart` accepts `Observation & { title: string; series: string; unit: string; points: Reading[] }` (`Observation = { source: string; asOf: string; timeLabel?: string }`, `Reading = { id: string; label: string; value: number | null }`). It provides **no `baseline`, `min`, or `yDomain` prop**.
- **Internal `0`-reducer domain behavior:** `Chart` computes:
  ```ts
  const lower = numeric.reduce((minimum, value) => Math.min(minimum, value), 0);
  const upper = numeric.reduce((maximum, value) => Math.max(maximum, value), 0);
  ```
  Because `0` is always included in `[lower, upper]`, plotting high-baseline raw NAV series (such as `998,500..1,004,200`) forces the vertical domain to `0..1,004,200`, flattening period variation.
- **Required Sourdough framing:**
  1. Never pass raw high-baseline NAV values into `Chart`. On `/paper/performance`, bind `Chart.points` exclusively to **percentage return (`%`)** or **cumulative P&L from zero** (where `0` is the true economic baseline), and display exact raw NAV, capital flows, and period deltas side-by-side in `RecordFacts` and `DataTable`.
  2. Preserve `Chart`'s built-in missing-value segmentation: points with `value === null || !Number.isFinite(value)` break the SVG `<path>` (`M...L...` segment restart, never interpolating across gaps or coercing to `0`), render `<small>No reading</small>` on missing ticks (`"No readings"` when all points are `null`), and populate `"No reading"` inside the built-in `<details><summary>View readings</summary><DataTable .../></details>` table.
  3. Never substitute `StatCard` (`@openboa/yogurt/motion-stat-card`, whose unexported internal helper `StatSeries` coerces non-finite values to `0`) for `Chart` on financial or close-incomplete series.
