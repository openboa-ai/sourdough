## Boundary and dependencies

Bind every global chrome surface, executive route, custom domain composition, confirmation gate, browser-agent policy, and telemetry chart in the Board Client strictly to verified `@openboa/yogurt` (`0.2.0-local.1`) and `@ui-sdk/react` / `@ui-sdk/core` (`0.1.0-beta.13`) APIs. All components consume service read models (`GET /v1/meta`, `GET /v1/projections/*`, `GET /v1/events`) and submit commands solely via `POST /v1/commands` and `GET /v1/commands/{command_id}?operation=...`. Per [Domain glossary](../../../glossary.md), `"P&L is an amount, return is a percentage. The client calculates neither."`—financial KPIs and `PortfolioChart` render service-projected figures only, and no domain or control-plane service depends on UI component bindings.

Input contracts: [Tokens and layout](../tokens-and-layout/spec.md) · [Client screens and navigation](../../inspect/screens/spec.md) · [Live trading and paper portfolio](../../inspect/investment-panel/spec.md) · [Office Floor Map](../../inspect/office-floor-map/spec.md) · [CEO Direct Line](../../governance/ceo-direct-line/spec.md) · [Approvals & Custody](../../governance/approvals-and-custody/spec.md) · [Flow observability](../../inspect/flow-observability/spec.md) · [Command submission](../../commands/submit/spec.md) · [Meta and authorized read projections](../../control-plane/projections/spec.md) · [Event stream, runtime wakeups, and typed commands](../../control-plane/commands-and-events/spec.md). These are public client and service contracts, not imports of service implementations.

#### Banned exports, patterns, and missing-symbol prohibitions

- **Prohibited Right Slide-Over Drawers (`Sheet` / `Y.Sheet` BANNED):** In `@openboa/yogurt` `0.2.0-local.1`, `Sheet` (`.yg-sheet`) renders a flush inline-end `100dvh` desktop right slide-over drawer. `Sheet` (`Y.Sheet`), `.yg-sheet`, and all right-hand inspector panes are **strictly prohibited across 100% of Sourdough Client routes and breakpoints**. Every item selection transitions the main workspace view (`Tier 0 -> Tier 1`) with `Breadcrumb` and deterministic focus recovery; confirmations use centered modal `ControlledConfirmDialog`. (If a narrow-viewport bottom drawer is ever used, use root `@openboa/yogurt` `Drawer`—inherently bottom-only `.yg-drawer` taking `DialogProps` with no `side` prop—or `@ui-sdk/react/drawer` `Drawer` constrained strictly to `side="bottom"`, never `"right"`/`"end"`.)
- **Prohibited Template Personas & Excluded Example Idioms:** Never use template persona variants or example shell identifiers in Sourdough code or fixtures. On `AgentAvatar`, use strictly the **13 non-template silhouettes (`38` `AgentVariant`s)**: `wide-oval-{top,bottom,right,left}`, `low-dome-{bottom,left,right}`, `round-triangle-{bottom,right,left}`, `tall-capsule-{top,bottom,right,left}`, `round-diamond-{left,right}`, `wide-base-{top,bottom,right}`, `wide-crown-{top,left,right}`, `tilted-oval-{top,bottom,left}`, `drop-{bottom,right,left}`, `round-star-{right,left}`, `bean-{top,bottom,left}`, `round-pentagon-{bottom,right,left}`, `round-heart-{right,left}`. Always pass an explicit `label` (Sourdough Agent display label + state) and set `animated={false}` for `10+` dense collapsed rows or `prefers-reduced-motion: reduce`.
- **Missing-export prohibitions:** Never cite absent symbol names as `@openboa/yogurt` exports:
  - Do not cite `Banner` or `Alert` (use `Notice` with `urgent={true}` for `role="alert"`).
  - Do not cite `Input` (use `TextField` or `@ui-sdk/react/input` styled with `.yg-input`).
  - Do not cite plural `Breadcrumbs` (use singular `Breadcrumb`).
  - Do not cite `Radio` (use `RadioGroup`), `NumericSpinner` (use `@ui-sdk/react/number-input`), `DatePicker` (use `@ui-sdk/react/date-picker`), or `Stat` / `Metric` / `KeyValue` (use `RecordFacts` or `Card` + `Text` with `tabular-nums`).
  - Do not import `Drawer` or `PageHeader` via subpath imports—both are root `@openboa/yogurt` exports only.
- **Missing-reading & formatting ban on `StatCard`:** `@openboa/yogurt/motion-stat-card` exports `StatCard`, which formats values using `value.toLocaleString()` only (no currency symbol, `+`/`-` sign, or `%`), draws a curved Catmull-Rom area fill expecting normalized `[0..1]` points, and coerces non-finite values to `0` (`Number.isFinite(value) ? value : 0`). Never use `StatCard` for financial, P&L, or sparse operational telemetry; use `Card` + `Text` (`tabular-nums`), `RecordFacts`, `PortfolioChart` / `Chart`, and `DataTable`.

### 3. Four custom domain compositions

Where a Sourdough domain need exceeds a single `@openboa/yogurt` atomic export, compose `@openboa/yogurt` tokens/components with `@ui-sdk/react` / `@ui-sdk/core` (`0.1.0-beta.13`) inside the Client presentation layer (never inside Python services):

### 4. `ControlledConfirmDialog`, `AgentReady`, and `createYogurtAgent` / WebMCP safety spec

#### 4.1 Why `ControlledConfirmDialog` builds the confirm button on `@ui-sdk/react/button` (`SDKButton`)

Inspected directly in `@openboa/yogurt` `0.2.0-local.1`:
- Yogurt `Button` (`packages/web/src/controls/actions.tsx:8-52`) types `onClick` as single-argument `MouseEventHandler<HTMLButtonElement>` and invokes `onClick?.(event)`, **dropping `@ui-sdk/react/button`'s second argument `details: ButtonActionDetails`** (`@experimental` in `@ui-sdk/core/button` / `@ui-sdk/react/button` `0.1.0-beta.13`; `{ source: "mouse" | "touch" | "pen" | "keyboard" | "virtual" | "programmatic" | "agent" }`).
- Yogurt `ConfirmDialog` (`packages/web/src/patterns/decisions.tsx:21-88`) wraps Yogurt `Button`, does **not** accept or forward `data-agent-confirm`, and passes zero `details` to `onConfirm`.

Therefore, Sourdough MUST NOT use unwrapped `ConfirmDialog` or Yogurt `Button` for mutating command confirmation. `ControlledConfirmDialog` composes `@ui-sdk/react/alert-dialog` (styled with `.yg-dialog` tokens) + `Stack` + `ButtonGroup` (`label="Decision"`, `justify="end"`) + quiet `Cancel` (`Button` `emphasis="quiet"`) + confirm trigger imported via `import { Button as SDKButton } from "@ui-sdk/react/button"` (`Button` is the actual exported symbol; `SDKButton` is the local alias) styled with Yogurt's `.yg-button` classes (`data-emphasis="filled"`, `data-tone={decision.destructive ? "danger" : "brand"}`, `data-control-size="regular"`, `data-shape="pill"`).

#### 4.2 Five mandatory invariants of `ControlledConfirmDialog`

1. **Revision latch (`opened.current`):** On `open === true`, latch `opened.current = { id: decision.id, revision: decision.revision }` once (covering composite preconditions such as `${company_id}:${charter_revision}:${expected_revision}`, `${question_id}:${revision}:${payload_hash}`, or `${restriction_id}:${expected_restriction_revision}:${charter_revision}`). Reset `opened.current = null` and `sent.current = false` when `!open`.
2. **Mid-review mutation detection (`changed`) & warning banner:** Compute `const changed = opened.current !== null && (opened.current.id !== decision.id || opened.current.revision !== decision.revision);`. When `changed` is true, render an inline `<Text className="yg-error" role="status">This decision changed. Close and review it again.</Text>` (or `Notice` `urgent={false}` with `role="note"` / `urgent={true}` with `role="alert"`, since `@openboa/yogurt` `Notice` hardcodes `role={urgent ? "alert" : "note"}` and accepts no `role` prop) and disable the confirm `SDKButton` (`disabled={!decision.available || !!changed || pending}`).
3. **One-shot submit guard (`sent.current`), `details.source` check & immediate modal handoff:** Inside confirm `SDKButton`'s `onClick(event, details)`:
   - First check `if (details?.source === "agent") { event?.preventDefault(); return; }` (rejects autonomous agent clicks across all **25 human-confirmed mutating governance/control commands**—excluding CEO-delegated retirement—while advisory `send_ceo_message` on `/ceo` Composer also enforces human `board_control` `details?.source !== "agent"` across all **26 total `POST /v1/commands` operations**). Whenever an async confirmation step crosses an `await` boundary before calling a UI-SDK controller, propagate `details.source` (`ButtonActionDetails`, `@experimental`) via `withSource(details.source, ...)` (`@experimental`, imported from `@ui-sdk/react/observe` or `@ui-sdk/core/observe`).
   - Guard against double-submit or stale latch: `if (sent.current || !decision.available || !opened.current || changed) return;`.
   - Set `sent.current = true;`, close immediately via `onOpenChange(false);`, and dispatch `onConfirm({ ...opened.current })` to `CommandOutboxPanel`.
4. **Distinct specific confirm verb & `#175174` / `danger` tone:** Use `<ButtonGroup label="Decision" justify="end">` with quiet `Cancel` on the start edge and an intrinsic-width confirm button whose verb names the specific consequence (e.g., `"Pause New Paper Orders"`, `"Resume Paper Trading"`, `"Amend Charter"`, `"Quarantine Review Tool"`, never generic `"OK"`). Non-destructive governance commitments use `tone="brand"` (`#175174`); destructive stops/revocations/quarantines/rollbacks use `tone="danger"`.
5. **Confirm-only `data-agent-confirm` placement:** Set a descriptive non-empty sentence `data-agent-confirm={decision.consequence}` **exclusively on the confirm `SDKButton`**—never `""`, never on dialog content, and never on `Cancel`.

#### 4.3 `AgentReady`, `createYogurtAgent`, WebMCP, and DOM redaction policy

- **Disabled by default (`allow: () => false`):** Any `createYogurtAgent({ allow })` bridge mounted in the Client defaults to `allow: () => false` (omitting `allow` is forbidden and throws a synchronous `TypeError: "A host action policy is required to create a Yogurt agent."`). When enabled by explicit host configuration for read-only inspection, `allow` permits **only** read-only `snapshot()` / `query()` inspection and rejects mutating `act()` steps (`allow` returns `false`): when `step.confirm` is present, `act()` fails with `"The person said no to \"<confirm text>\"."`; when no `confirm` string is present, `act()` fails with `"The app refused <action> on <ref>."`.
- **Explicit human-gate & no-rollback semantics:** `data-agent-confirm` does **not** block `act()` on its own when `allow` returns `true` (`act()` succeeds with `ok: true` and invokes handlers with `details.source === "agent"`): human safety relies on **both** `allow: () => false` (default) / rejecting `step.confirm` and mutating actions when opted in **and** `ControlledConfirmDialog`'s `details?.source === "agent"` handler rejection. `registerTools(agent, { allow })` (WebMCP `document.modelContext.registerTool`) marks `snapshot`/`query` `readOnlyHint: true`, `act` `consequentialHint: true`, and all tools `untrustedContentHint: true`. `agent.act({ steps })` executes sequentially without transaction rollback on later step failures.
- **Unique accessible labels, `keepMounted` isolation & Floor Map `definePrimitive`:** Every interactive control MUST carry a unique accessible label (`"Open <title>"`, `"Actions for <row>"`, zero substring collisions); modal dialogs using `keepMounted` MUST keep distinct labels isolated from background triggers. On `/office`, the custom Studio Floor Map `role="grid"` declares `agent: { actions: ["selectAgent", "focusZone"] }` inside `definePrimitive` (`@experimental` in `0.1.0-beta.13`, covered by Playwright keyboard verification).
- **Full `data-agent-hidden` and `data-agent-secret` matrix:**
  - `data-agent-hidden`: Applied to the Host-Lock Privacy Shield protected root (`host_locked`), host-denied `401`/`403` screens, `ControlledConfirmDialog` confirm regions under `board_viewer`/`controls_locked`, and ephemeral `Toast` overlays so `snapshot()`, `query()`, and `subscribe()` omit those subtrees completely.
  - `data-agent-secret`: Applied to `OwnerProof` challenge-response fields (`/bootstrap`), `InputOTP` / verification inputs, and any transient auth/session handle displays so `value`, `previous`, and `errors` read `"[redacted]"` in `snapshot()`, `act()`, and `subscribe()`.
- **Raw-HTML interactive `snapshot()` / `query()` caveat:** Several `@openboa/yogurt` `0.2.0-local.1` interactive components and sub-elements render raw HTML (`<a>`/`<button>`/`<details>`) rather than `@ui-sdk/react` primitives and are therefore omitted from `createYogurtAgent.snapshot()` / `query()` trees: `SidebarItem` (`<a>`/`<button>`), `SidebarSubmenu` (`<button>`), `AgentRow` (`<button>`), `DataTable` sort header buttons (`<button class="yg-table-sort">`), `DisclosureRow` (`<details>`), `ListRow` interactive triggers (`<a>`/`<button>` via `href`/`onActivate`), `ResourceRow` (`<button>` via `onOpen`), `Link` (`<a>`), `Chart` readings `<details>`, and `TaskList` step `<details>`. Independent Playwright/keyboard/screen-reader accessibility checks are REQUIRED on all routes using these controls rather than relying on `snapshot()` alone.

### 5. `PortfolioChart` & `Chart` high-baseline framing and `null`-gap honesty

Inspected directly in `@openboa/yogurt` `0.2.0-local.1` (`packages/web/src/controls/data.tsx:183-322`):
- **Verified `Chart` signature & internal `0`-reducer:** `Chart` accepts `Observation & { title: string; series: string; unit: string; points: Reading[] }` (`Observation = { source: string; asOf: string; timeLabel?: string }`, `Reading = { id: string; label: string; value: number | null }`) and renders a single series with `lower`/`upper` reduced starting from `0` (`Math.min(minimum, value)` / `Math.max(maximum, value)`). Plotting high-baseline raw NAVs (`998,500..1,004,200`) inside `Chart` flattens period variation against `0`.
- **Required Sourdough framing on `/` and `/performance`:**
  1. Never pass raw high-baseline NAV values into `Chart`. Bind `PortfolioChart` (Composition #3) and `Chart` points exclusively to service-projected **Cumulative Return (`%`, `0%` baseline)** or **Cumulative P&L (`$0` baseline)** with a dashed zero reference line (`--yg-brand-ink` primary line, `--yg-muted` dashed reference, `--yg-signal-positive`/`--yg-signal-limit` delta markers, `0` gradients), and display exact raw NAV, capital flows, and period deltas side-by-side in `RecordFacts` and `DataTable`.
  2. Preserve missing-value segmentation: points with `value === null || !Number.isFinite(value)` break the SVG `<path>` (`M...L...` segment restart, never interpolating across gaps or coercing to `0`), render `<small>No reading</small>` on missing ticks (`"No readings"` when all points are `null`), and populate `"No reading"` inside the collapsed `DisclosureRow` / `<details><summary>View readings</summary><DataTable .../></details>` table.
  3. Never substitute `StatCard` (`@openboa/yogurt/motion-stat-card`) for `PortfolioChart`, `Chart`, or KPI cards on financial or close-incomplete series.
