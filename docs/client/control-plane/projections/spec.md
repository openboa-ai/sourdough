## Boundary and dependencies

Expose read-only company, trading, floor-map, CEO-thread, governance, work, organization, operations, and separated offline-evaluation projections over `CompanyDaemon`'s UDS Control Plane (`GET /v1/meta` and `GET /v1/projections/*`). Reads NEVER mutate operational state, NEVER execute SQLite writes (including `Since Last Visit` `?since_seq=` queries), NEVER read `.desk/drafts/*` bodies, and NEVER compute synthetic client-side financial figures when domain coverage is missing.

Input contracts: [Transport, loopback bridge, and role authorization](../bridge-and-auth/spec.md) · [Authorized work timeline](../../../company/systems/operations/work-timeline/read/spec.md) · [Client screens and navigation](../../inspect/screens/spec.md) · [Flow observability](../../inspect/flow-observability/spec.md). These are public service contracts, not imports of client UI packages.

## Design decision and review

### 1. Reconciled `/v1/*` endpoint inventory (`35` concrete endpoints; `31` projections)

Serving the **5-area Executive Information Architecture + quiet lateral `SYSTEM` section** in [Client screens and navigation](../../inspect/screens/spec.md), the UDS Control Plane defines **`35` concrete `/v1/*` endpoints**:

- `1` capability/identity endpoint: `GET /v1/meta` (`[LIVE_UDS]` core 9 fields + `[BACKEND_GAP #2, #3, #8]` extended fields)
- **`31` concrete `GET /v1/projections/*` endpoints** (`1` `[LIVE_UDS]` `work-timeline` + `30` `[V1_SQLITE_NEEDS_UDS]` / `[BACKEND_GAP]` endpoints, including `floor-map`, `ceo-thread`, `3` two-segment paths `evaluations/{suites,grading,lineage}`, and `2` parameterized paths `work-runs/{run_id}`, `decision-trace/{order_id}`)
- `1` event stream endpoint: `GET /v1/events` (`[LIVE_UDS]` + `[BACKEND_GAP #8]` wakeups)
- `2` command/receipt endpoints: `POST /v1/commands` and `GET /v1/commands/{command_id}?operation=...`

### 2. Canonical `v1` (`6694fa9`) provenance taxonomy & 8-item Backend Gap List

Every endpoint, metric, and schema below carries one of three provenance tags verified against `openboa-ai/sourdough` `origin/main` (`6694fa9`):

- **`LIVE_UDS`**: Served end-to-end by `CompanyDaemon` (`src/sourdough/ipc/server.py`) in `6694fa9`.
- **`V1_SQLITE_NEEDS_UDS`**: Backed by verified Python/SQLite domain tables and services in `6694fa9`, awaiting UDS projection/handler wiring.
- **`BACKEND_GAP #1–#8`**: Capabilities absent from `6694fa9` `src/sourdough/`:
  - **`BACKEND_GAP #1`**: `sourdough client-web` loopback HTTP-to-UDS bridge + `(company_id, principal_id)` `0o600` `O_NOFOLLOW` `board-pending` + `403` stale-file quarantine.
  - **`BACKEND_GAP #2`**: `board_owner_challenge`/`board_binding`/`role_assignment` RBAC tables, `cli.py` `authorize_board` default wiring, `GET /v1/meta` identity fields, and `(principal_id, operation)` receipt scoping on `GET /v1/commands/{id}`.
  - **`BACKEND_GAP #3`**: Board ↔ CEO 1:1 Direct Line (`ceo_agent_id`, thread table, `GET /v1/projections/ceo-thread`, `send_ceo_message` failing closed on non-CEO targets, live `context_ref` status, CEO wake-on-message).
  - **`BACKEND_GAP #4`**: `DecisionQuestion`/`AcceptedAnswer`/`AnswerApplication`/`AnswerDelivery`, `amend_charter`, `revoke_grant` UDS handler, `decisions`/`charter`/`roles` projections, generalized dispatch registry.
  - **`BACKEND_GAP #5`**: Live streaming market quote / intraday unrealized MTM feed (`paper_valuation.py` in `v1` captures discrete sealed window slots only).
  - **`BACKEND_GAP #6`**: Modern Studio Floor Map metadata (`agent` table in `02_company_core.sql` stores only `(id, company_id, execution_profile)` — needs `display_name`, `role_title`, presentation zone hints, and `GET /v1/projections/floor-map`).
  - **`BACKEND_GAP #7`**: Multi-cause `RestrictionView` (`restriction` table, `pause_company`/`resume_company`, `paper-risk-command-v2`), `incidents` & `maintenance` tables/projections, 5-dim `RecoveryReceipt` gate (`release_restore_quarantine`), plus operational UDS handlers (`interrupt_run`, `cancel_work`, `change_paper_binding`, `configure/start_paper_runtime`, `cut_checkpoint`, `restore_checkpoint`).
  - **`BACKEND_GAP #8`**: In-daemon `CompanyRuntime` + post-commit `_event_cond.notify_all()` wakeups + `append_audit_event` across 13 silent `company.sqlite` modules & 2 coordinator-owned runtime/planner areas + `work_projection.py` upgrade + `?since_seq=` `Since Last Visit` digest on `company-overview-v1` + Flow 13 evaluator feed/poll adapter (`evaluator_store_attached`) & `offline-trial-registry-v2` `AccessRecord`/`parent_method_ids` + `work_custody_transfer` (`'blocked'` + `'awaiting_reassignment'`).

### 3. Headers, ETag caching, common envelope metadata, and anti-tear snapshot invariant

- **Request headers**:
  - `If-None-Match`: Exact quoted ETag (`"..."`) or weak `W/"..."` in comma-separated format. Wildcard `*` MUST be rejected (`400` / mismatch per `server.py:78-85`), never returning `304`.
  - Bridge-forwarded auth (`Authorization: Bearer` or port-bound `HttpOnly; SameSite=Strict` cookie) + `Host`/`Origin` pinning per [Bridge and auth](../bridge-and-auth/spec.md).
- **Response headers (all `GET /v1/meta` & `GET /v1/projections/*` replies)**:
  - `Connection: close`, `Cache-Control: no-store`, `X-Sourdough-Company-Id: <company_id>`, `X-Sourdough-Event-Seq: <int>`.
  - `ETag`: `"{revision}:{event_seq}"` for `work-timeline-v2` and all extended projections (`"{revision}"` preserved for legacy `work-timeline-v1`).
  - `304 Not Modified`: Empty body with `ETag`, `X-Sourdough-Event-Seq`, `X-Sourdough-Company-Id`, `Connection: close`, `Cache-Control: no-store`.
- **Common JSON envelope fields (`[LIVE_UDS]` `v2` + extended fields)**:
  - Every projection response embeds `{company_id, store_key, contract_revision, revision, as_of_ns, event_seq, service_incarnation_id}` where `store_key = "{dev}:{ino}"`, `revision = sha256(canonical_json(payload_body))`, `as_of_ns = time_ns()`, `event_seq = max_event_seq(connection, company_id)`, and `service_incarnation_id` (`[BACKEND_GAP #2]`) uniquely identifies the daemon incarnation (`uuid4()` per startup).
- **Single-`read_tx` + dual-`stat` anti-tear invariant (`work_projection.py:28-87`)**:
  - Every `company.sqlite` projection opens a single `open_reader(store)` (`mode=ro`, `PRAGMA query_only=ON`) `read_tx` snapshot, verifies `initial_stat` vs `post_tx_stat` via `os.stat(..., follow_symlinks=False)` (`st_dev`, `st_ino`, `st_uid`), computes `as_of_ns` and `event_seq` inside the same snapshot, and fails closed if the underlying store inode changed mid-read (such as during a checkpoint restore swap).
  - Unsupported projection names (`404` / `422`) or unsupported `contract_revision` query values (`400`) fail closed **before** accessing the SQLite store.
- **RBAC gating**: Under `bootstrap_locked` (zero active `board_binding` rows), all `GET /v1/projections/*` fail closed with `403`. Bound `board_viewer` and `board_control` principals receive projections filtered strictly by their active `role_assignment.scope_ref` and `audience`; unauthorized scope/entity access fails closed (`403`) or omits restricted evidence with `"Unavailable"` placeholders rather than leaking titles or metadata.
