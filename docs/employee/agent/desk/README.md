# A2 · Agent Desk

[System map](../../../README.md#system-hierarchy) · [Glossary](../../../glossary.md)

**Responsibility:** Resolve one Agent’s permitted working set, preserve private drafts and publish only explicitly shared revisions under current grants. Company custody survives a runtime loss. Only the original Agent on its bound profile reopens its private desk; a successor needs an explicit scoped share. Company resource custody remains independent.

## Agent-private working set

### [Reopen an Agent's personal workspace](intent.md)

A model transcript or a machine home directory is not the Agent's durable desk.

- [reopen](reopen/spec.md) — Rehydrate a private desk under current grants. Revoke a shared project between sessions. Its old reference cannot yield content; another Agent cannot enumerate the desk.
- [publish](publish/spec.md) — Create a scoped shared revision without publishing the desk or inheriting unrelated access.
