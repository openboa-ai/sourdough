# Reopen an Agent's personal workspace

Design draft · [Agent Desk](README.md) · [Company MVP map](../../../README.md) · [Development lifecycle](../../../engineering/lifecycle.md)

Business situation: [Work alone or with others](../../../capabilities.md#collaboration).

## Operating need

A model transcript or a machine home directory is not the Agent's durable desk.

## Observable outcome

The same Agent can recover permitted private notes and duties in a fresh session on its original runtime binding, then publish only an authorized selection to a shared company project. See [W1](../../../acceptance/episodes.md#w1-personal-work).

## Scope of discretion

Private means limited visibility inside company custody, not Agent ownership or automatic visibility to every colleague.

Publication to a company project is an authorized, explicit selection, not an assignment of work or a transfer of custody; the separate Work handoff records acceptance.
