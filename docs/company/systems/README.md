# Company systems

[Company responsibilities](../README.md) · [Ownership matrix](../../README.md#system-hierarchy)

Systems implement company responsibilities by enforcing authority, retaining authoritative records and performing or reconciling effects. They do not dictate an employee’s decisions. These are logical owners, not a fleet of required processes.
