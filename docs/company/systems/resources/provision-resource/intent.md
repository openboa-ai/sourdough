# Request and provision a company resource

Design draft · [Company resources](../README.md) · [Company map](../../../../README.md)

## Operating need

An Agent needs a scoped workspace, compute or external resource without a board action for each ordinary request. The company must retain custody and recover capacity when an assignment ends.

## Observable outcome

A request leads to an authorized, budgeted assignment and a usable scoped binding, or a recorded denial or outstanding duty. Hiring and the initial founder assignment remain possible without a pre-existing Agent session.

## Scope of discretion

An Agent can request and use resources within its grant. Organization, authority, finance and resource owners retain their distinct decisions; a request or budget alone does not grant access. Reads, writes and credentials remain separate.
